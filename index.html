Connecter le CRM

Vos fiches et vos notes d'appels sont rangées dans votre dépôt GitHub privé suivi-cpts-lyon, jamais dans cette page publique. Les clés ci-dessous restent dans ce navigateur : elles ne sont envoyées qu'à GitHub et à Allo. À faire une seule fois par ordinateur ou téléphone.

1. Jeton GitHub (obligatoire)

  1. Ouvrir la création du jeton (nom et durée sont déjà remplis)
  2. Repository access : Only select repositories, puis choisir suivi-cpts-lyon
  3. Permissions › Repository permissions › Contents : Read and write
  4. Generate token, copier le jeton et le coller ici

2. Clé Allo (synchro automatique des appels)

  1. Dans Allo : Réglages › API, créer une clé
  2. Autoriser la lecture des conversations (CONVERSATIONS_READ)
  3. Copier la clé (ak_live_…) et la coller ici
